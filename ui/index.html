ModelEffortTurn limit

The cap counts API-equivalent usage. On a Claude plan login it limits how much of your plan one session can use. An agent that hits a limit stops, and you can tell it to continue.

Permissions

Agents run with nobody there to click "allow", so anything not allowed here is refused. Only workers can edit files, and only in their own copy of the project.

A * at the end matches the rest of the command: npm test * also allows npm test -- --watch=false. Leave the box empty to take the shell away from them. Rules in the project's own .claude/settings.json still apply on top.
